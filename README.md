# 🎓 Website PKBM LAM ALIF

Website resmi **PKBM LAM ALIF** yang dibuat dengan konsep sederhana, modern, friendly, dan responsif.

Website ini dilengkapi dengan halaman informasi PKBM serta **formulir pendaftaran peserta didik yang dapat terhubung langsung ke Google Spreadsheet menggunakan Google Apps Script.**

---

## ✨ Fitur

- 🏠 Halaman Home
- 🏫 Informasi Tentang PKBM
- 📚 Informasi Program Pendidikan
- 🎓 Program Paket A
- 📖 Program Paket B
- 🎓 Program Paket C
- 📝 Formulir Pendaftaran Online
- 📊 Penyimpanan data pendaftaran ke Google Spreadsheet
- 📱 Responsive untuk HP, Tablet, dan Desktop
- 📞 Informasi kontak PKBM
- 🎨 Desain sederhana dan friendly

---

## 🛠️ Teknologi yang Digunakan

Website ini dibuat menggunakan:

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Spreadsheet
- Google Fonts - Poppins

Tidak membutuhkan framework seperti Bootstrap, React, Vue, atau Laravel.
